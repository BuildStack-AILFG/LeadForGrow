## 2026-09-21 — Fixed Google login always showing "Sign-in link expired"
Branch: main
Files: `app/auth/google/complete/page.js`
What changed: after a successful Google consent + callback, the completion page always displayed "Sign-in link expired. Please try again." Server log showed two `POST /api/auth/google/exchange` per sign-in — first 200, second 400. The exchange code is single-use (`findOneAndDelete`), and React StrictMode (dev) runs the effect twice: the first call consumed the code but its result was discarded by the effect's `cancelled` cleanup flag, so the second call's 400 was what got displayed. Replaced the `cancelled` flag with a `useRef` guard so the exchange fires exactly once per page load and its result is always applied. No server/route change — the single-use semantics are intentional (see the callback's "never put tokens in the redirect URL" comment).
Related decisions: none.
